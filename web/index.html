확률로 뽑되, 거짓말은 안 합니다

이 도구는 당첨 확률을 높이지 않습니다. 어떤 6개 조합이든 1등 확률은 정확히 같기 때문입니다. 대신 통계적으로 근거 있는 조합을 뽑아주고, 유일하게 실익이 있는 레버 — 공동당첨 분할위험 — 만 줄입니다.

모든 조합의 1등 확률
1 / 8,145,060
= C(45,6). 번호를 어떻게 고르든 이 값은 변하지 않습니다.

확률 기반 번호 생성기

모드를 고르고 번호 뽑기를 누르세요. 각 세트의 프로필과 분할위험 점수를 함께 보여줍니다.

아직 뽑은 번호가 없습니다. 번호 뽑기를 눌러보세요.
정직한 안내. 위 번호의 1등 확률은 다른 어떤 조합과도 동일한 1/8,145,060 입니다. ‘군중도(avoid)’는 실제 1등 당첨자 수 1,229회로 검증한 값(사람들이 덜 고르는 조합일수록 낮음, Spearman +0.27)이지만, 효과는 작습니다 — 최상·최하 극단이라야 당첨 시 분할이 약 1.23배 차이. 당첨 확률은 못 올리고, ‘당첨 시 덜 나눠 갖는’ 기대값만 소폭 개선할 뿐입니다. 오락비 한도 안에서만.

내 번호 진단

번호 6개를 넣으면 어떤 필터·패턴을 통과/위반하는지, 과거와 얼마나 겹치는지 보여줍니다.

실데이터 1,235회가 말해주는 것 — “최빈”은 답이 아니다

실제 1등 당첨자 수(= 그 조합을 몇 명이 골랐나)를 회귀분석해 “사람들이 몰리는 조합”을 역추론했습니다.

몰리는 조합 (피하기)

생일 편중(≤12 여러 개, z=+4.6, p<1e-5), 6개 전부 ≤31인 순수 생일조합, 낮은 합계, 균등 간격, 럭키7. 당첨되면 많이 나눠 갖게 됩니다.

희소 조합 (유리)

32~45 고번호 포함, 불규칙 간격, 합계 150~200. 실제로 공동당첨자가 적었습니다(검증 Spearman +0.27, p≈1e-22).

“최빈”의 진짜 위치

가장 많이 나온 번호 = 예측력 0(공정성 p=0.915). 게다가 대중이 따라 하는 유명 전략이라 공동당첨 위험은 오히려 커질 수 있음 → 비권장.

단, 효과크기는 작습니다: 최상·최하 십분위라야 당첨 시 분할이 1.23배 차이. 당첨 확률(1/8,145,060)은 불변. 여러 장 살 거라면 “서로소 5장(★추천)”이 45개 중 30개를 커버해 하위등수 적중률↑·분산↓까지 챙깁니다.
